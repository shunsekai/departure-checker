# Departure Checker

##　使用技術

- React
- Typescript
- Vite
- React Router
- CSS Modules
- Open-Meteo API

## 機能

### 港一覧

- 登録されている港を一覧表示

### 港名検索

- 港名を入力して表示する港を絞り込み

### お気に入り

- 港をお気に入りに登録・解除
- LocalStorageに保存

### 閲覧履歴

- 閲覧した港を履歴として保存
- 履歴から過去に見た港を確認

### 天気情報

- Open-Meteo APIから現在の風速・気温・風向を取得
- 天気情報の取得中・取得失敗時の状態を表示

### 出港判断

- ボートサイズを大型・中型・小型から選択
- 風速をボートサイズごとの基準と比較
- 「出港可能」「出港注意」「出港不可」を表示

## 工夫した点

- React Routerを使用してページごとのルーティングを実装しました
- LocalStorageを利用してお気に入りと閲覧履歴を保存しました
- Open-Meteo APIから現在の天気情報を取得しました
- 天気情報の取得中・取得失敗時の表示を分けて、状態が分かるようにしました
- ボートサイズごとに風速の基準を設定し、出港可能・出港注意・出港不可を判定できるようにしました
- TypeScriptを使用して状態やデータに型を設定しました

## 起動方法

```bash
npm install
npm run dev
```

ターミナルに表示されたURLにアクセスしてください

## ビルド

```bash
npm run build
```

## 注意事項

このアプリの出港判断は安全を保障するものではありません。
実際の出港については、気象情報や現地の状況を確認したうえで、ご自身で判断してください。

Weather data: Open-Meteo
